# 门店跟进治理功能使用说明

## 功能概述

门店跟进治理功能帮助您以自然周为单位管理和监测门店数据，主要包括：
- 每周筛选门店进行监测
- 每日查看"线索量-本地"、"到店数"、"到店率"三个指标的变化
- 手动填写跟进原因和备注
- 每周五生成统计报告

## 功能入口

访问 http://localhost:5003/follow_up

## 主要功能模块

### 1. 跟进任务管理

#### 创建新任务
1. 在左侧"跟进任务"面板中，选择周次（使用周选择器）
2. 点击"新建"按钮
3. 系统会自动创建本周的跟进任务

#### 选择监测门店
1. 点击"选择门店"按钮
2. 在弹出的模态框中：
   - 选择基准日期（用于获取门店基础数据）
   - 查看所有门店的三个指标数据：
     - 线索量-本地
     - 到店数
     - 到店率（自动计算 = 到店数 / 线索量 × 100%）
   - 点击列标题可按该指标升序/降序排列
   - 勾选需要监测的门店
   - 点击"确认选择"保存

#### 每日跟进记录
1. 选择跟进日期
2. 在门店列表中查看各门店的当日数据
3. 点击"编辑"按钮填写跟进原因

### 2. 跟进原因配置

#### 查看原因选项
左侧面板显示了所有预设的跟进原因选项，包括：
- 线索量正常，无需干预
- 线索量下降，已联系督导
- 线索量下降，已联系店长
- 线索量下降，等待自然恢复
- 门店积极配合，等待数据回升
- 门店不配合，已上报
- 到店率正常
- 到店率偏低，已提醒门店
- 到店率偏低，门店已采取措施
- 其他原因

#### 管理原因选项
- 点击原因选项旁边的开关图标可以启用/禁用该选项
- 点击垃圾桶图标可以删除该选项
- 点击右上角的"+"按钮添加新的原因选项

### 3. 填写跟进原因

#### 操作步骤
1. 在门店列表中点击目标门店的"编辑"按钮（铅笔图标）
2. 在弹出的跟进原因填写框中：
   - 从预设选项中选择原因（支持多选，点击切换）
   - 在备注框中补充额外说明（如需要）
3. 点击"保存"按钮

### 4. 查看门店数据趋势

#### 操作步骤
1. 在门店列表中点击目标门店的"趋势"按钮（趋势图标）
2. 在弹出的趋势查看窗口中：
   - 默认显示最近7天的数据
   - 可以自定义日期范围进行查询
   - 查看三个指标的趋势图表：
     - 线索量-本地（蓝色实线）
     - 到店数（绿色虚线）
     - 到店率（橙色实线）
   - 查看详细数据表格，包含每日变化对比
   - 变化值以颜色区分：红色表示下降，绿色表示上升

#### 功能特点
- 图表展示：直观的折线图展示数据变化趋势
- 日期筛选：支持自定义日期范围查询
- 数据对比：显示每日与前一天的变化量
- 颜色区分：上升显示绿色，下降显示红色

### 5. 生成周统计报告

#### 生成报告
1. 点击"生成报告"按钮
2. 系统自动生成包含以下内容的报告：
   - 周次和监测门店数
   - 各门店每日跟进情况
   - 跟进原因统计汇总

#### 使用报告
- 点击"复制报告"按钮将报告复制到剪贴板
- 报告格式为纯文本，可直接粘贴到文档或邮件中

### 6. 删除任务

如需删除当前任务，点击"删除任务"按钮（需二次确认）

## 数据库表结构

### 跟进任务表 (跟进任务)
| 字段 | 类型 | 说明 |
|------|------|------|
| 任务ID | INTEGER | 主键 |
| 周开始日期 | TEXT | 本周开始日期 |
| 门店列表 | TEXT | JSON格式存储的门店数据 |
| 状态 | TEXT | 进行中/已完成 |
| 创建时间 | TEXT | 创建时间戳 |

| 字段 | 类型 | 说明 |
|------|------|------|
| 记录ID | INTEGER | 主键 |
| 任务ID | INTEGER | 外键关联任务 |
| 日报数据日期 | TEXT | 跟进日期 |
| 店编号 | TEXT | 门店编号 |
| 店简称 | TEXT | 门店简称 |
| 线索量-本地 | TEXT | 线索量数据 |
| 到店数 | TEXT | 到店数数据 |
| 跟进原因 | TEXT | 填写的跟进原因 |
| 备注 | TEXT | 额外说明 |
| 创建时间 | TEXT | 创建时间戳 |

### 跟进原因配置表 (跟进原因配置)
| 字段 | 类型 | 说明 |
|------|------|------|
| 配置ID | INTEGER | 主键 |
| 原因选项 | TEXT | 原因内容 |
| 排序 | INTEGER | 显示顺序 |
| 状态 | TEXT | 启用/禁用 |
| 创建时间 | TEXT | 创建时间戳 |

## 典型工作流程

### 周一
1. 打开功能页面
2. 选择本周周次，点击"新建"
3. 点击"选择门店"，选择需要监测的门店
4. 根据线索量、到店数、到店率排序，筛选重点关注门店
5. 确认选择

### 周一至周四
1. 每天打开页面
2. 选择当天日期
3. 查看监测门店的各项指标
4. 对异常门店点击"编辑"，选择跟进原因并填写备注

### 周五
1. 点击"生成报告"
2. 查看本周汇总数据
3. 点击"复制报告"
4. 将报告粘贴到周报文档中

## 注意事项

1. 基准日期选择：选择门店时，请选择最近的有完整数据的日期作为基准
2. 数据更新：每日日报导入后，门店的指标数据会自动更新
3. 报告生成：建议在周五完成所有跟进记录后再生成报告
4. 原因配置：可以根据实际工作需要添加、修改、删除跟进原因选项
