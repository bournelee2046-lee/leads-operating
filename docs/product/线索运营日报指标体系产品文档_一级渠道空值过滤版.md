> **文档版本**：V1.1（按最新 `main(1).py` 口径修订）\
> **修订日期**：2026-05-12\
> **适用产品**：门店数据分析工具（线索日报版）\
> **目标读者**：数据产品经理、数据分析师、业务运营人员

## 一、文档概述

### 1.1 产品定位

本工具用于基于**线索数据**、**到店数据**和**门店信息表**，自动生成店端、大区、战区、巡回员四个层级的线索运营日报，用于监控线索跟进效率、到店转化、异常门店及组织层级运营表现。

### 1.2 核心数据源

此处暂时留空，先构建页面和指标。

### 1.3 数据周期定义

| 时间维度       | 程序口径                                    |
| :--------- | :-------------------------------------- |
| 本月         | 目标日期所在年月内，且 `日期 <= 目标日期` 的数据            |
| 本日         | `日期 = 目标日期` 的数据                         |
| 三天三次跟进专项截止 | 在“本月”数据基础上，再限定 `线索下发时间 < 目标日期 18:00:00` |

> 说明：大多数指标按 `日期` 字段切分本月/本日；三天三次跟进率额外使用 `线索下发时间` 和目标日期当天 18 点进行判断。

### 1.4 适用层级

| 报表    | 统计维度  |
| :---- | :---- |
| 店端日报  | `店编号` |
| 大区日报  | `大区`  |

## 二、数据预处理规则


### 2.2 门店信息关联规则


线索表、到店表均通过 `店编号` 与门店信息表关联。若线索表或到店表中已存在 `大区` 字段，会先删除原字段，再以门店信息表中的组织字段为准。

门店信息表至少应包含以下字段：

| 字段          | 用途                    |
| :---------- | :-------------------- |
| `店编号`       | 关联键，必须存在              |
| `大区`        | 组织维度                  |
| `大区督导`      | 店端展示维度                |
| `大区经理`      | 店端展示维度                |
| `战区`        | 组织维度                  |
| `战区经理`      | 店端展示维度                |
| `巡回员`       | 组织维度                  |
| `店简称`       | 店端日报展示字段，若模板或输出需要则应提供 |

### 2.3 数据过滤规则

| 过滤位置      | 规则                                                                           |
| :-------- | :--------------------------------------------------------------------------- |
| 线索数据导入预处理 | 线索表仅统计 `一级渠道 = '线上'` 的记录；`一级渠道` 为空、缺失或 `一级渠道 = '线下'` 的线索均不进入后续任何线索类指标统计      |
| 渠道值合法性理解  | 对线索数据而言，`一级渠道` 只有明确为 `线上` 或 `线下` 才视为有效渠道值；其中 `线下` 会被排除，最终进入线索指标统计的只有 `线上` 线索 |
| 到店数据导入预处理 | 到店表剔除 `一级渠道 = '线下'` 的记录；到店指标仍按到店表自身字段统计                                      |
| 三天三次跟进率   | 在本月线上线索基础上，只统计 `线索下发时间 < 目标日期 18:00:00` 的线索                                  |

> **说明**：本次口径调整后，线索表中 `一级渠道` 为空的记录不再参与线索量、有效线索量、30分钟跟进、三天三次跟进、N60专项、线索有效率及各类以线索为分母或分子的转化指标计算。

### 2.4 日期格式兼容处理

程序对以下字段进行混合日期格式兼容转换：

```text
日期、线索下发时间、首次云外呼时间、首次手工跟进时间
```

支持格式：

| 格式类型     | 示例           | 处理方式                 |
| :------- | :----------- | :------------------- |
| 标准日期字符串  | `2026-05-10` | `pd.to_datetime()`   |
| 8位数字     | `20260510`   | 按 `%Y%m%d` 解析        |
| Excel序列号 | `45423`      | 以 `1899-12-30` 为基准转换 |

在三天三次跟进率计算内部，程序还会将 `线索下发时间`、`首跟时间`、`二跟时间`、`三跟时间` 转换为日期时间类型。

### 2.5 布尔字段转换：是否30分钟跟进

导入阶段若存在 `是否30分钟跟进` 字段，程序会转换为布尔值：

| 原始值                          | 转换结果    |
| :--------------------------- | :------ |
| 布尔型 / `np.bool_`             | 保持原值    |
| `'true'`、`'1'`、`'是'`、`'1.0'` | `True`  |
| 其他非空值                        | `False` |
| 空值 / NaN                     | `False` |

## 三、核心指标口径定义

### 3.1 线索量指标

#### 3.1.1 线索量（总）

```text
本月_线索量 = COUNT(本月内，一级渠道='线上')
本日_线索量 = COUNT(本日内，一级渠道='线上')
```

说明：该指标按 `店编号` 或组织维度分组统计。`一级渠道` 为空或为 `线下` 的线索不计入线索量。

#### 3.1.2 本地线索量

```text
本月_线索量_本地 = COUNT(本月内，一级渠道='线上'，且 是否异地线索 = '否' 的线索)
本日_线索量_本地 = COUNT(本日内，一级渠道='线上'，且 是否异地线索 = '否' 的线索)
```

说明：本地线索量不要求 `跟进截止时间` 不为空，但仍要求 `一级渠道='线上'`。

#### 3.1.3 有效线索量

```text
本月_有效线索量 = COUNT(本月内，同时满足以下条件的线索：
    一级渠道 = '线上'
    且 是否有效 ∈ {'是', '有效'}
    且（线索大类 = '新媒体-经销店'
       或 线索大类 = '新媒体' 且 线索小类包含 '经销商'）)

本日_有效线索量 = 同上，限定本日数据
```

#### 3.1.4 本地有效线索量

```text
本月_有效线索量_本地 = COUNT(本月内，同时满足以下条件的线索：
    一级渠道 = '线上'
    且 是否异地线索 = '否'
    且 是否有效 ∈ {'是', '有效'}
    且（线索大类 = '新媒体-经销店'
       或 线索大类 = '新媒体' 且 线索小类包含 '经销商'）)

本日_有效线索量_本地 = 同上，限定本日数据
```

#### 3.1.5 线索有效率

当前程序中，**店端日报**与**大区/战区/巡回员日报**的线索有效率计算口径存在差异，应按以下方式理解。

##### 店端日报口径

店端日报中，线索有效率使用一个中间分母：经销商相关新媒体线索量。该中间分母不直接作为最终展示字段输出。

```text
店端 本月_线索有效率 = 本月_有效线索量 / 本月经销商相关新媒体线索量
店端 本日_线索有效率 = 本日_有效线索量 / 本日经销商相关新媒体线索量
```

其中：

```text
经销商相关新媒体线索量 = COUNT(
    一级渠道 = '线上'
    且（线索大类 = '新媒体-经销店'
       或 线索大类 = '新媒体' 且 线索小类包含 '经销商'）
)
```

##### 大区

汇总层级中，程序基于店端结果重新汇总：

```text
汇总层 本月_线索有效率 = SUM(本月_有效线索量) / SUM(本月_线索量)
汇总层 本日_线索有效率 = SUM(本日_有效线索量) / SUM(本日_线索量)
```

其中 `本月_线索量` / `本日_线索量` 为跟进截止时间不为空的线索量。

### 3.2 跟进效率指标

> 本节所有线索跟进类指标均基于 `一级渠道='线上'` 的线索计算；`一级渠道` 为空或为 `线下` 的线索不参与统计。

#### 3.2.1 30分钟跟进数

```text
本月_30分钟跟进数 = SUM(本月内，一级渠道='线上'，且跟进截止时间不为空的线索的 是否30分钟跟进)
本日_30分钟跟进数 = SUM(本日内，一级渠道='线上'，且跟进截止时间不为空的线索的 是否30分钟跟进)
```

布尔值 `True` 记为 1，`False` 记为 0。

#### 3.2.2 30分钟跟进率

```text
本月_30分钟跟进率 = 在本月、一级渠道='线上'、且跟进截止时间不为空的线索中，是否30分钟跟进字段的均值
本日_30分钟跟进率 = 在本日、一级渠道='线上'、且跟进截止时间不为空的线索中，是否30分钟跟进字段的均值
```

说明：该指标在程序中使用 `mean()` 计算；若某门店或分组没有符合条件的线索，后续 `本月_` / `本日_` 字段空值填充时会显示为 0。

#### 3.2.3 三天三次跟进率

##### 第一步：确定统计范围

```text
cutoff = 目标日期当天 18:00:00
仅统计 线索下发时间 < cutoff 的线索
```

该逻辑建立在“本月”数据基础上，即目标日期所在年月内且 `日期 <= 目标日期`。

##### 第二步：剔除规则

以下线索不计入分子和分母：

| 剔除条件                                                   | 说明              |
| :----------------------------------------------------- | :-------------- |
| `跟进截止时间` 为空                                            | 无法判断跟进任务，不参与考核  |
| `一级渠道 != '线上'`                                         | 仅考核线上线索         |
| `线索状态 = '跟进中'` 且 `二跟时间` 为空 且 `线索下发时间 >= cutoff - 72小时` | 仍处于可跟进周期，暂不参与考核 |

##### 第三步：计算跟进次数

```text
跟进次数 = 1（默认）
若 二跟时间 不为空 → 跟进次数 = 2
若 三跟时间 不为空 → 跟进次数 = 3
```

##### 第四步：判断是否满足

当前最新程序的分子规则为：

| 跟进次数  | 满足条件                                      |
| :---- | :---------------------------------------- |
| 1次    | `是否30分钟跟进 = True`                         |
| 2次或3次 | `是否30分钟跟进 = True` 且 `二跟时间 - 首跟时间 <= 72小时` |

> 重要：当前程序针对二跟及以上线索，只考核“二跟 - 首跟”的时间差是否不超过 72 小时，不再单独考核“三跟 - 首跟”的时间差。

##### 第五步：汇总计算

```text
本月_三天三次跟进任务数 = 未被剔除的线索数量
本月_三天三次跟进数 = 满足条件的线索数量
本月_三天三次跟进率 = 本月_三天三次跟进数 / 本月_三天三次跟进任务数
```

### 3.4 到店转化指标

#### 3.4.1 到店数

```text
本月_到店数 = 引用客流统计表中线上进店客流的字段，限定时间范围为本月
本日_到店数 = 同上，限定时间范围为本日

本日_线索到店率_本地 = 本日_到店数 / 本日_线索量_本地
本日_有效线索到店率 = 本日_到店数 / 本日_有效线索量
本日_有效线索到店率_本地 = 本日_到店数 / 本日_有效线索量_本地
```

## 四、层级汇总规则

### 4.1 店端日报

店端日报以 `店编号` 为统计维度，输出门店基础信息、本月指标和本日指标。

### 4.2 大区日报

当前程序采用“**店端结果汇总 + 线索明细重新聚合**”的混合方式。

| 指标类型                      | 程序处理方式                                                                  |
| :------------------------ | :---------------------------------------------------------------------- |
| 三天三次跟进率                   | 在 `group_daily_summary()` 中基于线索明细，按 `大区` 重新计算任务数、跟进数和跟进率 |
| 30分钟跟进率                   | 基于本月/本日且跟进截止时间不为空的线索明细，按组织维度求 `是否30分钟跟进` 均值                             |
| 线索量、有效线索量、到店数、N60线索数等数量指标 | 多数基于店端结果按组织维度求和                                                         |
| 到店率、有效线索到店率、本地到店率等比率      | 基于汇总后的分子分母重新计算                                                          |
| 门店总数                      | 分组内店编号数量                                                                |

## 五、空值与异常处理规则

### 5.1 本月/本日字段空值填充

所有字段名以 `本月_` 或 `本日_` 开头的列，最终会执行空值填充：

```text
NaN → 0
```

### 5.2 除法计算函数

程序中多项到店率、有效率、占比使用如下规则：

```python
def calc_arrival_rate(numerator, denominator):
    if numerator is NaN or numerator == 0:
        return 0
    if denominator is NaN or denominator == 0:
        return 1
    return numerator / denominator
```

注意：`30分钟跟进率` 不是通过该函数计算，而是通过 `mean()` 计算。

### 5.3 百分比展示

程序在生成 DataFrame 时，会把多数百分比列转换成字符串形式：

```text
0.855 → "85.50%"
```

导出 Excel 时，程序会再将百分比字符串转换回数值并设置 Excel 数字格式：

```text
"85.50%" → 0.855，单元格格式为 0.00%
```

## 十、术语表

| 术语        | 含义                                    |
| :-------- | :------------------------------------ |
| 本月        | 目标日期所在月，从1日至目标日期                      |
| 本日        | 目标日期当天                                |
| 本地线索      | `是否异地线索 = '否'` 的线索                    |
