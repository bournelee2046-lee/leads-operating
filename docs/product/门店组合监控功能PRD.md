# 门店组合监控功能 PRD

## 1. 背景与目标

门店组合监控用于让运营人员按一个规则圈定一批门店，形成可长期观察的“组合”。组合只用于观察门店指标变化，不产生治理任务，不修改线索状态，不影响门店管理里的状态维护。

核心不是“系统自动盯盘”，而是“用户基于需求选出一批门店，并持续监控这些门店的运营日报指标”。

## 2. 术语

- 组合：若干门店的集合。用户最终观察的是组合。
- 默认规则：配置中心里维护的规则模板，只在新增组合时作为模板使用。
- 选店指标：用于规则筛出候选门店的指标，可多选。
- 观测指标：组合建立后用于看趋势和明细的指标。观测指标至少包含选店指标，也可以额外选择。
- 组合门店：组合内已确认的门店集合。移出后不自动补位。

## 3. 页面结构

### 3.1 主页面：门店组合监控

路由：`/dealer-management/store-portfolio-monitor`

主页面展示：

- 左侧“监控组合”列表
- 左侧“新增组合”按钮
- 每个组合右侧编辑按钮
- 右侧当前组合看板
- 顶部“配置中心”入口

主页面不展示默认规则配置表单。

### 3.2 配置中心页面

路由：`/dealer-management/store-portfolio-monitor/config`

配置中心是独立页面，不展示左侧监控组合列表，避免用户误以为在修改当前组合。

配置中心功能：

- 管理默认规则
- 新增默认规则时所有字段为空
- 删除默认规则需要确认弹窗
- 预览默认规则会生成哪些候选门店
- 保存后只影响未来新增组合，不修改已有组合

### 3.3 新增组合页面

路由：`/dealer-management/store-portfolio-monitor/new`

点击“新增组合”不会直接创建组合，而是进入新增组合页面。

新增组合页面流程：

1. 选择一个默认规则作为模板
2. 系统带出默认规则字段
3. 用户可临时调整本次组合条件
4. 系统生成组合门店预览
5. 用户可手动移出门店
6. 用户可在“可添加门店”中按推荐候选或搜索门店编码/门店名加入
7. 点击“创建组合”后才真正生成组合

### 3.4 编辑组合页面

路由：`/dealer-management/store-portfolio-monitor/:portfolioId/edit`

编辑组合只允许：

- 修改组合名称
- 增减观测指标
- 手动移出组合门店
- 手动加入组合门店
- 删除组合

编辑组合不允许修改创建时使用的完整规则配置。规则只读展示。

## 4. 关键业务规则

### 4.1 默认规则与组合解耦

配置中心维护的是默认规则，不是组合。

默认规则变化后：

- 后续新增组合可沿用新默认规则
- 已创建组合的规则、门店集合、观测指标不被自动同步

### 4.2 组合建立后的规则锁定

组合创建后，创建时的规则作为只读快照保存在组合中。

允许改：

- 名称
- 观测指标
- 门店集合

不允许改：

- 时间范围
- 区域范围
- 选店指标
- 选店方式
- 命中模式
- 门店状态
- 阈值
- 门店数量

### 4.3 门店移出不自动补位

无论在新增组合预览还是编辑组合时，用户移出门店后：

- 系统不自动用下一名候选补位
- 组合数量可以减少
- 用户必须在“可添加门店”里手动补充

### 4.4 指标选择

选店指标支持运营日报所有主要指标，允许多选。

观测指标默认包含选店指标，且选店指标不可从观测指标中取消。用户可以额外选择其他运营日报指标。

### 4.5 图表

主页面“当前指标”切换同时影响：

- 门店指标对比
- 组合趋势

门店指标对比：

- 先选择组合内一家门店
- 图表展示该门店在当前日期范围内每日相对前一日的涨跌变化
- 使用正负柱状图表达变化程度
- 不展示左侧刻度值
- 少日期时柱体不稀疏，长日期时自动压缩日期标签

组合趋势：

- 展示当前组合在日期范围内的指标趋势
- 品牌均值以虚线展示
- 图例放右上角
- 组合和品牌均值都显示数值
- 不展示左侧刻度值

## 5. 数据边界

该功能为只读观察工具。

允许：

- GET 门店日报聚合数据
- GET 单店逐日指标序列
- 前端本地保存组合和默认规则原型状态

禁止：

- 创建治理任务
- 修改线索跟进状态
- 修改门店治理状态
- 写入运营日报源数据
- 调用 POST/PATCH/DELETE 类型业务接口

## 6. 验收清单

- 点击配置中心进入独立页面，左侧监控组合不显示
- 点击新增组合进入独立页面，不直接生成组合
- 新增默认规则时字段为空
- 新增组合选择默认规则后才带出模板内容
- 组合创建后规则不可编辑
- 移出门店后不自动补位
- 可添加门店支持门店编码和门店名搜索
- 当前指标切换能同时影响两个图表
- 图表无左侧刻度值
- 组合趋势图例在右上角
- 只新增 GET 数据接口，无业务写接口
