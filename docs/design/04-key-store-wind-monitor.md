# 重点店风向监测指标体系 - 设计文档

## 概述

本文档定义「重点店风向监测」功能的设计方案。该功能以11家重点门店（10家商贸重点店 + 1家非商贸重点店）为"监测样本"，构建一套趋势优先、绝对值辅助的风向指标体系，用于辅助判断品牌整体线索运营的健康走向。

**核心设计理念**：借鉴PMI指数中的样本企业思路 —— 样本不必是最大的，但需要其趋势具有指向性。通过"趋势一致性"、"拐点同步性"、"绝对值偏离度"三重镜面，对品牌整体运营状态进行监测。

---

## 1. 功能定位

| 维度 | 说明 |
|------|------|
| 功能名称 | 重点店风向监测 |
| 监测样本 | 11家重点店（10家商贸重点店 + 1家非商贸重点店） |
| 定位 | 样本监测点 —— 通过样本变化趋势判断品牌整体走向 |
| 分析维度 | 趋势一致性（主）+ 绝对值偏离度（辅） |
| 趋势/绝对值比例 | 7:3（趋势指标7个，绝对值指标3个） |

### 1.1 与被监测业务指标的关系

监测框架（10个风向指标）与被监测的业务指标是解耦的：

```
固定层：10个风向监测指标（T1-T7, A1-A3）
  ↓ 通过配置表驱动
配置层：业务指标配置表（可增删改）
  ↓ 当前初始配置
业务指标：[30分钟跟进率, 三天三次跟进率, 线索有效率, 到店率, 转化率, N60跟进率]
```

- 新增业务指标：只需在配置表加一行 + 数据预计算加一列
- 替换业务指标：只需修改配置表 + 确保预计算覆盖
- 10个风向监测指标的**计算逻辑无需任何改动**

### 1.2 可配置参数

| 参数 | 默认值 | 可选值 | 说明 |
|------|--------|--------|------|
| 统计窗口天数 | 7天 | 7 / 14 / 30 | 用户可在页面切换 |
| 被监测的业务指标 | 6个 | 可增删 | 通过配置表管理 |

## 2. 指标体系定义

### 2.1 趋势类指标（7个，占比70%）

#### T1 - 同步率
| 属性 | 说明 |
|------|------|
| 定义 | 过去N天，对于某个业务指标，重点店组合的环比变动方向（↑/↓）与全品牌一致的**天数 ÷ N** |
| 覆盖范围 | 所有活跃的业务指标分别计算 |
| 综合值 | 各业务指标同步率的算术平均 |
| 最优区间 | > 80%（绿），60-80%（黄），< 60%（红） |
| 业务含义 | "重点店组合的方向变化与全品牌一致的程度" |
| 权重 | 30%（在T7综合得分中） |

#### T2 - 拐点同步率
| 属性 | 说明 |
|------|------|
| 定义 | 在N天窗口内，当某业务指标出现方向转折（升→降或降→升），重点店组合与全品牌**同日发生转折**的指标数 ÷ 发生转折的总指标数 |
| 覆盖范围 | 所有发生拐点的业务指标 |
| 综合值 | 拐点同步发生的比例 |
| 最优区间 | > 60%（绿），40-60%（黄），< 40%（红） |
| 业务含义 | "重点店能否及时跟随品牌整体的拐点变化" |
| 权重 | 20% |

#### T3 - 趋势斜率比
| 属性 | 说明 |
|------|------|
| 定义 | 重点店组合的N天日均环比变动幅度 ÷ 全品牌的N天日均环比变动幅度 |
| 覆盖范围 | 所有活跃的业务指标分别计算后取中位数 |
| 综合值 | 各指标斜率比的中位数 |
| 最优区间 | 0.8 ~ 1.2（绿），0.5-0.8 或 1.2-2.0（黄），< 0.5 或 > 2.0（红） |
| 业务含义 | "重点店的变化幅度相对于全品牌是否合理"（太陡说明样本过于敏感，太平说明样本反应迟钝） |
| 权重 | 15% |

#### T4 - 趋势背离天数
| 属性 | 说明 |
|------|------|
| 定义 | 当前连续几天重点店组合的方向与全品牌不一致（取6个指标中背离天数最多的值） |
| 覆盖范围 | 所有活跃的业务指标 |
| 综合值 | 最大连续背离天数 |
| 最优区间 | 0天（绿），1-2天（黄），≥3天（红，建议关注干预） |
| 业务含义 | "当前有没有出现持续的背离信号，背离越久越需要关注" |
| 权重 | 15%（反转计分：0天=100分，5天以上=0分） |

#### T5 - 先行指标数
| 属性 | 说明 |
|------|------|
| 定义 | 在N天窗口内，重点店组合在某指标上先于全品牌发生趋势变化的指标个数 |
| 覆盖范围 | 所有活跃的业务指标 |
| 综合值 | 先行指标计数（0-6） |
| 最优区间 | 越高越好（越多指标有先行能力，样本的预警价值越强） |
| 业务含义 | "有多少个指标上，重点店能作为品牌整体的先行风向标" |
| 权重 | 10% |

#### T6 - 趋势稳定性
| 属性 | 说明 |
|------|------|
| 定义 | 6个业务指标的变异系数（标准差÷均值）的平均值 |
| 覆盖范围 | 所有活跃的业务指标 |
| 综合值 | CV均值 |
| 最优区间 | < 0.3（绿，稳定可预测），0.3-0.5（黄），> 0.5（红，波动大） |
| 业务含义 | "重点店组合的表现是否稳定，越稳定越有参考价值" |
| 权重 | 10% |

#### T7 - 综合趋势得分
| 属性 | 说明 |
|------|------|
| 定义 | T1-T6 加权汇总，0-100分 |
| 计算公式 | 见下表 |
| 最优区间 | ≥80（绿，风向明确），60-79（黄，部分存疑），< 60（红，需要关注） |

| 子指标 | 权重 | 计分方式 |
|--------|------|----------|
| T1 同步率 | 30% | 直接使用百分比值 |
| T2 拐点同步率 | 20% | 直接使用百分比值 |
| T3 趋势斜率比 | 15% | 在0.8-1.2区间的得满分线性衰减至0 |
| T4 趋势背离天数 | 15% | 0天=100, 1天=80, 2天=50, 3天=25, ≥4天=0 |
| T5 先行指标数 | 10% | 0个=0, 1-2个=50, 3-4个=75, 5-6个=100 |
| T6 趋势稳定性 | 10% | CV<0.3=100, 每增加0.1减20分，最低0分 |

### 2.2 绝对值类指标（3个，占比30%）

#### A1 - 均值偏离度
| 属性 | 说明 |
|------|------|
| 定义 | (重点店组合某指标均值 - 全品牌均值) ÷ 全品牌均值 × 100% |
| 覆盖范围 | 所有活跃的业务指标分别计算 |
| 综合值 | 各指标偏离度的均值 |
| 最优区间 | -10% ~ +10%（绿），-20%~-10%或+10%~+20%（黄），超出±20%（红） |
| 业务含义 | "重点店的指标水平相对于全品牌平均水平的差距" |
| 注 | 正值=高于整体，负值=低于整体 |

#### A2 - 样本离散度
| 属性 | 说明 |
|------|------|
| 定义 | 11家店某指标的标准差 |
| 覆盖范围 | 所有活跃的业务指标分别计算 |
| 综合值 | 各指标标准差的均值 |
| 最优区间 | 越小越好。逐步变大时标记橙色（说明样本店之间分化加剧） |
| 业务含义 | "11家店之间的一致性，标准差越大说明样本的代表性越需要谨慎对待" |

#### A3 - 样本有效店数
| 属性 | 说明 |
|------|------|
| 定义 | 11家店中该业务指标有数据的门店数 |
| 覆盖范围 | 所有活跃的业务指标分别计算 |
| 综合值 | 各指标有效店数的均值 |
| 最优区间 | 11/11（绿），8-10/11（黄），< 8/11（红） |
| 业务含义 | "当天的样本覆盖率，覆盖率低时其他指标的可信度打折扣" |

## 3. 数据模型设计

### 3.1 新增表：metric_key_store_wind（DuckDB）

风向监测预计算结果表，每条记录对应一个业务指标在某天的监测数据。

```sql
CREATE TABLE metric_key_store_wind (
    calc_date       DATE        NOT NULL,    -- 计算日期
    window_days     INTEGER     NOT NULL,    -- 统计窗口天数（7/14/30）
    metric_name     VARCHAR     NOT NULL,    -- 业务指标名（如 follow_in_30min_rate）

    -- 重点店组合（11家店汇总）
    ks_avg          DOUBLE,                   -- 重点店组合均值
    ks_median       DOUBLE,                   -- 重点店组合中位数
    ks_std          DOUBLE,                   -- 重点店组合标准差（即A2）
    ks_count        INTEGER,                  -- 有数据的店铺数（即A3）
    ks_prev_avg     DOUBLE,                   -- 重点店上一期均值（用于计算环比方向）

    -- 全品牌（所有店汇总）
    all_avg         DOUBLE,                   -- 全品牌均值
    all_prev_avg    DOUBLE,                   -- 全品牌上一期均值

    -- 衍生标记（用于趋势类指标计算）
    ks_direction    INTEGER,                  -- 重点店方向：1=上升, -1=下降, 0=持平
    all_direction   INTEGER,                  -- 全品牌方向：1=上升, -1=下降, 0=持平
    is_same_direction BOOLEAN,                -- 方向是否一致（T1的基础）
    slope_ratio     DOUBLE,                   -- 趋势斜率比（T3）
    deviation_rate  DOUBLE,                   -- 均值偏离度（A1）

    created_at      TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    PRIMARY KEY (calc_date, window_days, metric_name)
);
```

### 3.2 新增表：config_wind_metrics（DuckDB）

业务指标配置表，定义哪些业务指标被纳入风向监测。

## 4. 数据计算流程

### 4.1 计算触发时机

在现有 `compute_all_metrics()` 执行时，自动追加风向监测的预计算步骤：

```
原始数据 (leads.db)
    ↓
[现有] mart_leads + report_dealer_daily
    ↓
[现有] metric_daily / metric_weekly / metric_monthly
    ↓
[新增] metric_key_store_wind
    │
    ├── Step 1: 读取活跃指标列表（从 config_wind_metrics WHERE is_active = TRUE）
    ├── Step 2: 读取窗口天数配置（从 config_wind_settings）
    ├── Step 3: 对每个窗口 × 每个指标，计算重点店组合和全品牌的汇总值
    ├── Step 4: 计算衍生字段（方向、同步、斜率比、偏离度）
    └── Step 5: 写入 metric_key_store_wind
```

### 4.2 计算伪代码

```python
def compute_key_store_wind(db: DuckDBConnection, window_days_list: List[int], active_metrics: List[dict]):
    for window_days in window_days_list:
        for metric in active_metrics:
            metric_key = metric['metric_key']
            direction_type = metric['trend_direction']
            
            # 重点店组合汇总
            ks_data = db.execute(f"""
                SELECT 
                    date_id, 
                    AVG({metric_key}) as ks_avg,
                    MEDIAN({metric_key}) as ks_median,
                    STDDEV({metric_key}) as ks_std,
                    COUNT(*) as ks_count
                FROM metric_daily
                WHERE dealer_id IN (SELECT dealer_id FROM mart_dealers WHERE is_key_store = TRUE)
                  AND {metric_key} IS NOT NULL
                GROUP BY date_id
                ORDER BY date_id
            """).fetchall()
            
            # 全品牌汇总
            all_data = db.execute(f"""
                SELECT 
                    date_id, 
                    AVG({metric_key}) as all_avg
                FROM metric_daily
                WHERE dealer_id != 'all'
                  AND {metric_key} IS NOT NULL
                GROUP BY date_id
                ORDER BY date_id
            """).fetchall()
            
            # 计算方向和衍生字段
            for each date:
                ks_direction = compare(ks_avg, ks_prev_avg)
                all_direction = compare(all_avg, all_prev_avg)
                is_same = (ks_direction == all_direction)
                slope_ratio = abs(ks_avg - ks_prev_avg) / abs(all_avg - all_prev_avg)  # 安全除法
                deviation_rate = (ks_avg - all_avg) / all_avg
                
            # UPSERT 到 metric_key_store_wind
```

### 4.3 T4-T7 动态计算（查询层）

T4-T7 涉及到跨指标/跨日期的聚合判断，在查询 API 层实时计算而非预存储：

- **T4 趋势背离天数**：查询最近N天 `is_same_direction` 字段，计算连续为 FALSE 的天数
- **T5 先行指标数**：将每个指标的 `ks_direction` 变化点与 `all_direction` 变化点对比
- **T6 趋势稳定性**：从 T4-T5 的数据中计算 CV
- **T7 综合趋势得分**：加权汇总 T1-T6

### 6.2 各区域设计详情

#### A区 - 顶部概览

| 元素 | 位置 | 形式 | 内容 |
|------|------|------|------|
| 页面标题 | 左上 | 文字 | "重点店风向监测" + 页头说明 |
| 综合趋势得分卡 | 左1 | 大号数字 + 环比箭头 + 渐变色环 | 显示T7得分（0-100），如「82分 ▲+3」，得分≥80=绿色，60-79=橙色，<60=红色 |
| 指标结构环 | 左2 | 环形图（Donut Chart） | 10个监测指标按权重颜色分块展示 |
| 趋势/绝对值占比 | 左3 | 百分比卡 | 「趋势指标 7个 / 绝对值 3个」，波浪条展示70%/30%比例 |
| 窗口选择器 | 右 | 下拉/按钮组 | 7天 / 14天 / 30天 切换，切换后联动刷新B/C/D/E |

#### B区 - 趋势镜面表格（主视觉区）

- 7列：业务指标名、T1同步率、T2拐点同步率、T3趋势斜率比、T4背离天数、T5先行标记、T6稳定性
- 同步率 ≥ 80% 绿色，60-80% 黄色，< 60% 红色
- 背离天数 > 0 时高亮橙色；≥3天时红色
- T3斜率比在0.8-1.2区间为绿色，否则为橙色
- T6稳定性：低=绿色（CV<0.3），中=黄色，高=红色
- 底部一行汇总：全指标均值
- 点击任意行 → C区对应小图高亮/D区对应行高亮
- 鼠标悬停单元格 → tooltip显示该指标的近7日每日方向明细

#### C区 - 时间序列图表

- 6个小面积图（2行 × 3列）并排展示
- 每个图两条线：深蓝色=重点店组合均值，浅灰色=全品牌均值
- X轴=日期，Y轴=指标值（百分比带%后缀）
- 当两条线方向背离时，背景出现淡红色警示带
- 点击任意小图 → 展开为该指标的全宽大图（带十字准星和图例）
- 大图模式包含：环比变化数值、当前背离状态文字说明

#### D区 - 绝对值镜面表格（辅助区）

- 7列：业务指标名、重点店组合均值、全品牌均值、A1偏离度、A2离散度、A3有效店数、趋势方向标记
- 偏离度 > 10% 或 < -10% → 高亮
- 离散度逐渐变大 → 标记橙色（说明样本分化加剧）
- 默认展示，可通过右上角"收起"按钮折叠
- 最后一行汇总

#### E区 - 11家店明细表

- 默认折叠，通过"展开11家店明细 ▼"按钮展开
- 列：店简称 + 6个业务指标值 + 趋势方向箭头
- 底部汇总行：重点店均值 / 全品牌均值 / 差额（蓝色背景突出）
- 支持点击列头排序（方便找出拖后腿的店）
- 每行末尾有迷你趋势箭头：相比上一期 ↑ / ↓ / →
- 点击某店行 → 弹出该店的迷你趋势面板（6个指标近N日走势）

### 6.3 联动交互

| 触发 | 效果 |
|------|------|
| B区点击某行（某指标） | C区对应小图高亮/放大，D区对应行高亮 |
| C区点击某小图 | 展开为全宽大图模式 |
| 窗口天数切换 | A/B/C/D/E 全部联动刷新 |
| E区点击某店行 | 弹出该店迷你趋势面板 |
| D区点击"收起" | 折叠绝对值镜面表格 |
