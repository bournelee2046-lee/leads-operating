# 门店组合监控技术实现文档

## 1. 实现原则

正式系统实现必须以原型 `prototypes/store-portfolio-monitor-prototype.html` 为交互基准。

实现原则：

- 用路由表达页面，而不是只在同一页面切状态
- 配置中心、新增组合、编辑组合都是独立页面语义
- 默认规则与组合状态分离
- 后端只提供只读数据接口
- 前端不调用任何治理、状态修改、任务创建接口

## 2. 前端路由

入口路由：

- `/dealer-management/store-portfolio-monitor`
- `/store-portfolio-monitor`

子页面路由：

- `/dealer-management/store-portfolio-monitor/config`
- `/dealer-management/store-portfolio-monitor/new`
- `/dealer-management/store-portfolio-monitor/:portfolioId/edit`
- `/store-portfolio-monitor/config`
- `/store-portfolio-monitor/new`
- `/store-portfolio-monitor/:portfolioId/edit`

组件内部根据当前路径派生页面模式：

- `dashboard`
- `config`
- `create`
- `edit`

页面模式与 UI 关系：

- `dashboard`：显示左侧监控组合
- `edit`：显示左侧监控组合
- `config`：隐藏左侧监控组合
- `create`：隐藏左侧监控组合

## 3. 前端状态模型

### 3.1 DefaultRule

默认规则字段：

- `id`
- `name`
- `period`
- `customStart`
- `customEnd`
- `region`
- `selectionMetrics`
- `observeMetrics`
- `chartMetric`
- `sortDirection`
- `matchMode`
- `threshold`
- `count`
- `storeStatus`

新增默认规则必须使用空对象，不预填名称和选项。

### 3.2 Portfolio

组合字段包含默认规则快照，并额外包含：

- `id`
- `memberIds`
- `createdAt`
- `dataStart`
- `dataEnd`
- `chartStoreId`
- `locked`
- `updatedAt`

组合创建后 `locked = true`。编辑组合时只允许修改：

- `name`
- `observeMetrics`
- `memberIds`
- `chartStoreId`

### 3.3 CreateDraft

新增组合草稿：

- 初始为空
- 用户选择默认规则后，复制默认规则生成草稿
- 规则条件变化时重新生成推荐预览
- 用户手动移出门店后不自动补位
- 点击“创建组合”才写入前端组合列表

## 4. 数据接口

### 4.1 获取门店列表

`GET /api/store-portfolio-monitor/stores`

参数：

- `start_date`
- `end_date`
- `period`
- `region`
- `zone`
- `store_status`
- `dealer_id`
- `dealer_name`
- `sort_by`
- `sort_order`
- `page`
- `page_size`

用途：

- 默认规则预览
- 新增组合预览
- 组合门店明细
- 可添加门店候选

权限：

- 复用 `dealer_daily_report.query`

### 4.2 获取单店日序列

`GET /api/store-portfolio-monitor/daily-series`

参数：

- `dealer_id`
- `metric`
- `start_date`
- `end_date`

用途：

- 门店指标对比的每日涨跌图
- 组合趋势聚合

限制：

- 最大日期跨度 60 天
- 仅支持运营日报指标白名单

## 5. 页面交互状态机

### 5.1 配置中心

进入：

- 主页面点击“配置中心”
- 跳转 `/config`

行为：

- 隐藏左侧组合
- 展示默认规则列表
- 展示默认规则表单
- 展示新增组合门店预览

退出：

- 点击返回组合
- 跳转主页面

### 5.2 新增组合

进入：

- 左侧点击“新增组合”
- 跳转 `/new`

行为：

- 隐藏左侧组合
- 草稿为空
- 选择默认规则后复制模板
- 调整规则后刷新预览
- 手动移出后不自动补位
- 可搜索未加入门店并加入

提交：

- 校验草稿完整性
- 创建组合
- 跳回主页面并选中新组合

### 5.3 编辑组合

进入：

- 点击组合卡片右侧铅笔按钮
- 跳转 `/:portfolioId/edit`

行为：

- 显示左侧组合
- 规则只读展示
- 可修改名称、观测指标、门店集合
- 删除组合需要确认

退出：

- 保存组合后回主页面

## 6. 图表实现

使用 Recharts。

门店指标对比：

- `BarChart`
- 数据结构：`day`, `value`, `delta`
- `delta = 当日值 - 前一日值`
- `delta >= 0` 使用绿色
- `delta < 0` 使用红色
- `YAxis hide`
- `ReferenceLine y=0`
- 日期标签按数据量自动 `interval`

组合趋势：

- `LineChart`
- 组合线为实线
- 品牌均值为虚线
- `YAxis hide`
- 数值标签展示
- 图例由面板右上角自定义展示
